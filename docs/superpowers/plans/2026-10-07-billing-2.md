## Decisions

- One Credit is represented by 1,000,000 integer microcredits. Prices and currency
  conversion use Decimal, with no float input accepted. The cumulative operation
  total is rounded upward once to microcredits; incremental deltas use that total.
- Formal charging defaults off until operators configure actual model prices,
  currency conversion and audited opening grants. Failed operations default to
  retaining provider costs without charging users. There is no permanent per-user
  exemption or guessed legacy-to-Credits conversion.
- Durable attempts are committed before external calls. An interrupted external
  request remains pending reconciliation; no claim of exactly-once external API
  delivery is made. Ledger writes use database constraints and transactions.
- Reservations are admission headroom, never a fabricated upper cost bound. Actual
  known overrun is recorded as debt and blocks further admission; unknown cost
  remains visibly pending. No new hard Agent turn/call budget is introduced.
- Preserve unknown historic purchased rights and report them for verification;
  only source-proven history is repaired. No historical usage backbilling.
