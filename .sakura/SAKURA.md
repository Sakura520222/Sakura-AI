# Sakura AI Reviewer 项目概述

## 1. 项目简介与技术栈
基于大语言模型的智能 GitHub 代码审查与 Issue 分析机器人，具备跨文件依赖理解、全仓库扫描和项目记忆能力。
- **技术栈**：Python 3.11+ / FastAPI / MySQL & Redis / LLM & RAG / Docker / GitHub App & Telegram Bot

## 2. 架构设计与关键决策
采用后端分层架构，前后端同仓：
- `backend/api/`：路由；`core/`：配置与依赖注入；`models/`：数据结构
- `backend/services/`：核心业务（AI审查、记忆系统、RAG等）
- `backend/workers/`：异步任务；`telegram/`：Bot交互；`webui/`：前端
- **关键决策**：业务规则 YAML 外部化热更新；耗时任务 Worker 隔离；容器化交付。

## 4. 审查发现的重要模式
- **渐进式补洞**：每轮"补洞"而不触及设计边界，正则过滤输入是典型创可贴修复
- **"替换mock"系统性风险**：mock 隐含简化假设，替换时必须逐一重新审视
- **防御性代码"隐形流失"**：用真实实现替换时倾向丢弃防御层
- **"接收但忽略"反模式**：参数被接收后完全丢弃，调用方产生错误假设
- **双数据源一致性裂缝**：主路径与 fallback 返回对象结构不同
- **回退链异常语义侵蚀**：`NotImplementedError` 表示"不支持"而非"未实现"，异常作控制流时类型选择影响可读性
- **零评论高分走过场**：内部分析有价值但未输出，"好的分析不去表达等于没有分析"
- **行为变更伪装Bug修复**：懒加载改急加载、property改普通属性，即使上下文是修复也须按接口变更审查
- **增量审查陷阱**：隧道视野、找问题凑数拔高严重度、对照清单打勾忽略清单外副作用
- **净减代码蜜糖效应**：需区分减少的是业务逻辑（好）还是防御代码（危险）
- **`asyncio.gather` 暗礁**：默认任一异常取消全部
- **微小 Diff 欺骗性**：增量高质量≠PR可合并

## 5. 团队约定与规范
### 代码规范
- 跨模块复杂数据禁止裸 `dict`，必须用 `Pydantic`/`dataclass`/`TypedDict`
- 文件路径操作必须使用 `pathlib`，安全场景严格禁止 `Pure` 系列
- 魔法数字≥2次必须提取为常量；双数据源须标注过渡期和收敛计划
- 移除防御性代码必须有等价替代或显式风险声明（`# SAFETY: ...`）

### 审查规则（按优先级）
| 规则 | 级别 | 触发条件 |
|------|------|----------|
| PR级阻断表强制 | P0 | 遗留 critical 每次必须出现，状态只可更新不可删除 |
| quick approve 检查 | P0 | approve 前必须确认遗留 critical 为 0，否则自动降级 |
| 历史阻断机制 | P0 | 未闭环 error/critical 时增量审查禁止 approve |
| 强制拦截词 | P0 | PR 含高危词时锁定 approve 权限 |
| 遗留降级禁令 | P0 | 禁止 Critical/Error 降级为 Suggestion |
| 零评论高分拦截 | P0 | 评分 ≥ 8 时主要评论不能为空，必须写出论证 |
| 安全遗留轮次衰减 | P0 | 安全关注点 N 轮未修复，第 N+1 轮强制升级为历史遗留阻断 |
| 评分评论支撑 | P0 | 评分必须有评论，9分以上需说明优点 |
| PR规模策略校验 | P0 | 文件>10 禁止 quick 策略 |
| 严重度三问法 | P1 | 标记 major 前：①实际bug？②运行时错误？③安全风险？全否降级；接口契约违反例外 |
| 输出自检让步降级 | P1 | 描述含"虽然…但…"让步句式且让步否定核心风险，必须降级 |

| 变更文件零遗漏 | P1 | 输出前对照文件列表逐项确认覆盖 |
| 行为变更追溯 | P1 | 懒加载改急加载、property改属性等须追溯所有调用方确认兼容性 |
| 并行化失败审查 | P1 | 串行改 gather 必须检查 return_exceptions、部分成功处理 |
| 防御代码移除审查 | P1 | diff 中删除 if/try/except 必须确认新代码有等价保护 |
| 路径安全硬拦截 | P1 | 涉及路径拼接且无 .resolve() 直接 error，AST 拦截必须实现 |
| 适配器接口契约验证 | P1 | 必须列出被适配对象所有公共方法/属性，逐一确认 |
| 参数静默忽略禁止 | P1 | 签名含参数但实现完全忽略，必须抛异常/记录 warning/文档标注 |
| 双数据源类型一致 | P1 | 主路径+fallback 返回类型必须共享基类或 Protocol |
| 入口静默失败升级 | P1 | 扫描入口处静默回退至少为 minor |
| 增量上下文引用 | P1 | 含历史上下文时必须输出问题状态更新表 |
| 同提交重复审查拒绝 | P1 | 复审时提交 hash 未变应直接拒绝 |
