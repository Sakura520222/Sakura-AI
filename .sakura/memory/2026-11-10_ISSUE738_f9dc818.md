- **优先级**：`high` 的判断准确。P0 涉及权限边界 + 数据正确性（ReviewResponse 字段缺失会导致 PR 链接跳错），P1 涉及 AI 回退链静默丢弃这类数据丢失隐患，均非低危体验问题。关键词匹配未产生误判。

### 2. 标签推荐质量

- `bug/enhancement/test/refactor` 贴切；`security` 的置信度 0.7 与"尚无复现证据"的定位吻合。

- **P0 拆分合理**：先以 A/B 隔离回归测试锁定权限边界（含缓存与账号切换），再修 ReviewResponse 并要求前端用三段式构造链接且缺字段显示不可用——这与"正确性 > 展示"原则一致。

### 6. 经验教训

- **聚合型 Issue 的标准处理范式**：本 Issue 一次聚合多类问题，最佳实践是"定锚点 + 分层拆解 + 每层绑定回归测试"，且每层独立验收。分析结果已体现，建议沉淀为该类 Issue 的固定模板。
