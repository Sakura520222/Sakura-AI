### 2. 发现的模式

**代码模式**：

**架构观察**：

### 3. 规范完善建议

**新增审查规则**：
1. **配置废弃清理规范**：当配置字段被废弃时，必须同时从 `config.py`、UI 配置页面和动态配置键列表中移除，并在 PR 描述中说明迁移方案。
2. **i18n 标点完整性检查**：新增 UI 文本必须检查标点符号是否已纳入翻译键，避免混合语言标点。
3. **参数传递路径审查**：对于多来源参数（如函数参数 + overrides），需在代码注释中明确优先级和用途，避免冗余设置。

**项目特有规范**：
- **Shell 工具安全文档**：在 `shell_tool.py` 的 docstring 中明确说明黑名单模式与工作区隔离的设计取舍，特别是 `rm` 等命令的风险接受度。
- **SSE 日志一致性**：强制要求所有 SSE 相关文件使用模块级 logger 导入，并在延迟导入时添加原因注释。
