### 6. 经验教训与仓库沉淀
1. **Loguru 桥接的固有陷阱**：
   - 依赖标准 logging 桥接到 Loguru 时，`depth` 探测需要注意跳过 logging 内部帧；同时在 Python 中拦截 `exc_info` 时，需通过 `opt(exception=record.exc_info)` 安全传递，避免直接覆盖或在二次捕获时丢失 traceback。
2. **安全脱敏与性能平衡**：
   - 全链路统一 Sanitizer 避免在主事件循环内使用低效/回溯复杂的正则表达式。对长 Prompt / Completion 等大文本块，应仅做头部/元数据校验或限制扫描深度，防正则 ReDoS 与 CPU 尖峰。
3. **基础设施改造的拆解交付模式**：
   - 横切关注点（Cross-cutting concerns）重构绝不能“大步跨越”。必须严格贯彻分析中的分阶段策略：**先修基建缺陷（异常栈丢失 + Docker 日志上限）保证生产稳定，再做业务侵入性改造（全库语法替换 + 链路 Context 注入）**，利于 PR 审查与追溯。
