*   **Release Notes 中的 Breaking Change 隐藏点**：
    *   SQLAlchemy 2.1 对 `greenlet` 的解耦是极易被忽视的隐患。单看代码增量仅是版本号变更，但若不核对 Release Notes，很可能导致生产环境 `pip install` 部署后在运行时抛出 `ImportError`。**对依赖库 minor 级升级检查 Release Notes 必须作为标准动作。**
