## 4. 经验教训

### 值得关注的要点
- **公共函数提取不等于安全**：即使逻辑正确，边界值和 None 安全性仍须单独审查。

### 技术/模式审查经验
- **`str.removeprefix` vs `startswith + 切片`**：行为差异在于 `removeprefix("/")` 只移除一个前导 `/`，而 `startswith + 切片` 若写成 `endpoint[1:]` 会错误移除任意多个字符。当前实现正确，但可读性差。经验：**项目应强制使用 `removeprefix` 以降低认知负担**。
- **测试中临时 Provider 的 try/finally**：优秀模式，可推广到其他涉及全局配置的测试。
