* **警惕“衔尾蛇”效应（Ouroboros Pattern）**：自动化系统分析失败产生的错误日志，被当做新的 Issue 内容再次喂给自动化系统分析。对于 `automated` 标签的 Issue，分析器应具备**“元认知”能力**——识别出当前内容是“系统自身的历史报错”，从而走特殊的静默关闭或转人工流程，而不是尝试对其进行常规的业务分析。
* **“Safe”前缀函数的信任陷阱**：正如项目记忆强调的“错误响应函数不可黑盒信任”。名为 `safe_xxx` 的降级函数往往在 Code Review 中容易被放松警惕，但其恰恰是内部信息泄漏的高发区。未来审查需对所有 `safe/fallback/graceful` 关键字的函数进行严格的输出审计。
