### 2. 发现的模式

*   **代码模式：恢复/重试契约中的参数物理钳制**
    *   **现象**：在防御性编程中，虽然入口处对入参进行了 `effective_val = max(min_v, min(val, max_v))` 的钳制，但在构造建议/重试载荷（recovery payload / retry arguments）时，容易顺手使用函数原始形参（`val`）而非钳制后的局部变量（`effective_val`）。
*   **架构观察：AI Agent 工具间的协同契约**
    *   `read_file` -> `search_in_files` -> `list_directory` 三者边界清晰化。当工具检测到错用（如对目录调 `read_file`）时，通过返回结构化的 Recovery 引导模型转向正确工具，这是典型的 Agent 自愈模式。但各工具对通用参数（如 `context_lines`）的防御策略需保持一致（均需钳制）。

#### 建议新增规则：** Recovery 与重试载荷的参数防御同源原则**
