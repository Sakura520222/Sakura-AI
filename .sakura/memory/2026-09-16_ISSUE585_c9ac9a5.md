| 场景 | 经验教训 | 具体建议 |

| **自动同步冲突频发** | 自动合并 `main` → `develop` 在有大量元数据文件的仓库容易产生冲突。 | - 将自动同步改为 **手动触发**（在 PR 合并后由维护者执行）。<br>- 在工作流中加入 **冲突检测**：`git merge --no-ff --no-commit` → 若出现冲突直接 **标记失败** 并发送提醒，而不是创建 Issue。 |
