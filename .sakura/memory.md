# 项目记忆

## 审查模式与教训
- **规则替代判断**：规则与实际冲突时须回溯适用性
- **分析否定则降级**：得出"本身安全"时必须降级或移除
- **路径安全证明责任**：须构造具体攻击路径，禁止假设链标记major
- **resolve()位置决定安全语义**：前检查拦截所有symlink，后检查只拦截仓库外
- **"部分修复"比"未修复"更危险**
- **修复有效性须推演执行流**：死代码是典型假修复
- **except ImportError是降级信号**：回退链中抛非降级异常几乎都是bug
- **增量审查陷阱**：隧道视野、零评论高分、上下文浪费、**打勾陷阱**（零风险变更空评论=正确输出）
- **评分决策解耦**：增量质量高≠可合并，未闭环critical时decision必须降级；**评分须反映审查输出质量而非仅代码修复质量**
- **防御代码隐形流失**：diff删除防御结构须确认等价保护
- **好的分析不表达=没分析**
- **遗留"存而不查"是假记忆**：价值在复用，复用前提是触发
- **回滚陷阱**：破坏性回滚比新增更危险
- **策略按风险密度选**：不看代码量，并发/公开接口等高密场景禁用quick
- **PR描述覆盖校验**：每个改动点须映射审查评论，未覆盖须说明；多轮审查描述范围大于diff是正常现象
- **公开接口强制三维度**：契约、错误处理、返回值语义缺一不可
- **TOCTOU显式评估**："先查后操作"须评估并发，结论可接受也须声明
- **评论去重与合并**：主评论区禁止复制摘要；同位置不同表述必须合并为一条评论
- **执行流验证**：不只确认"是否调用"，须验证调用时上下文是否满足前置条件
- **审查提示词=审查状态机**：须画状态转移图，条件分支无降级出口即缺失Error State
- **静默降级须声明**：核心链路非核心依赖的静默吞错须注释表达"预期即失败"
- **suggestion疲劳归档**：第2轮未修复即降级为suggestion，第3轮强制归档并从主评论移除
- **微小增量精简**：quick下小范围纯修复，报告≤200字，颗粒度须与策略对齐
- **模式复制焦点转移**：已验证一致时从"正确性"转向"适配性"；**必须显式列出与原模式的所有差异点及理由**
- **修复验证须含调用链**：标"已修复"须验证上下游一致，否则标"待验证"
- **quick历史问题协议**：历史追踪项在quick下只进摘要表格；**增量变更与追踪项完全无交集时可省略追踪表**
- **修复即清除标签**：问题修复后从主评论移除，仅保留在已修复追踪表
- **决策状态同步**：所有critical/major已修复或归档且无新增阻塞项时，decision必须升级为approve/comment
- **归档≠阻塞**：技术债务归档意味着"已知且接受"，不应继续影响当前决策
- **状态机思维**：评论标签是状态标识，状态变更后标识必须同步更新
- **空评论结构约束**：quick下无新增问题时主评论强制为空，**从输出模板层面取消输出区域，而非依赖模型判断**
- **规则执行防形式化**：根因是生成倾向填充空白，解决方向是结构约束而非再写规则
- **复合问题拆分约束**：一条评论含多个独立子问题时必须编号枚举，部分修复标"部分修复"
- **根因修复验证**：问题描述引用高危区标签时，修复验证须回溯高危区核心要求
- **历史问题消失检测**：每轮须显式清点上一轮所有open项去向，禁止无痕消失
- **问题描述粒度决定闭环质量**：复合问题写一条→只修明显部分→假闭环
- **验证性内容≠suggestion**：修复确认误标suggestion会导致归档逻辑混乱
- **"已有模式"≠可接受**：与既有代码一致的问题不等于可放过，应标warning并归档为技术债务
- **防御代码复制须验证必要性**：模式复制时须评估新场景是否需要同等防御强度
- **增量审查边界感**：须区分"本次引入的问题"和"本次暴露的已有问题"

## 代码高危区
- **路径安全**：resolve()跟随symlink；三层防护范式
- **适配器接口契约**：首次审查须列所有公共方法逐一确认
- **回退链异常语义**：禁止NotImplementedError表示"不支持"
- **参数静默忽略**：违反为major
- **动态类型反模式**：type()动态构造绕过静态检查
- **类型守卫双重语义**：isinstance可能承担契约验证，移除须评估
- **接口实现删除**：列消费者→确认完备性→无法确认按critical
- **结构化数据解析**：每字段类型假设须显式校验
- **降级链隔离**：每阶段独立异常边界
- **try/except边界审计**：标记可能抛异常表达式→确认范围→确认捕获
- **str.find()返回-1切片陷阱**：须显式验证
- **无契约鸭子类型**：隐式依赖使删除/替换无法静态发现
- **去重key设计**：默认值碰撞、维度不足、丢弃无日志均为反模式
- **布尔参控制行为**：改变返回值类型是职责模糊信号
- **错误处理策略分裂**：同服务内抛异常vs静默降级共存，单PR无法根治须升级为技术债务决策
- **双路径对称性**：多路径解析的后处理逻辑结构一致性是核心不变量

## 严重程度判定
- **三问法强制绑定**：[major]前须内联三问答案；**三问中任一答案为"无"或"不涉及"时自动降级为minor**
- **自评矛盾自动降级**：正文出现"非安全用途/影响极小/风险可控/理论上/虽然功能正确"时，**对应标签自动降级一级**
- **纯可读性封顶规则**：不涉及功能/安全/数据完整性的可读性问题，封顶为suggestion
- **安全类禁止降级**：已证明被防护时允许降级
- **评论格式硬校验**：[major]/[critical]须含文件:行号+问题+影响
- **分区标签解耦**："建议（可选）"禁止major/critical
- **quick噪声过滤**：纯改善性建议在quick下不提出
