# 项目记忆

## 审查模式与教训
- 规则替代判断：规则与实际冲突须回溯适用性
- 分析否定则降级：得出“本身安全”须降级或移除
- 路径安全证明责任：须构造具体攻击路径，禁止假设链标记major
- resolve()位置决定安全语义：前检查拦截所有symlink，后检查只拦截仓库外
- “部分修复”比“未修复”更危险
- 修复有效性须推演执行流：死代码是典型假修复
- except ImportError是降级信号：回退链中抛非降级异常几乎都是bug
- 增量审查陷阱：隧道视野、零评论高分、上下文浪费、打勾陷阱
- 评分决策解耦：未闭环critical时decision必须降级；评分须反映审查输出质量而非仅代码修复质量
- 防御代码隐形流失：diff删除防御结构须确认等价保护
- 好的分析不表达=没分析
- 遗留“存而不查”是假记忆：价值在复用，复用前提是触发
- 策略按风险密度选：高密场景禁用quick
- PR描述覆盖校验：每个改动点须映射审查评论；提交含PR描述外变更须标注
- 公开接口强制三维度：契约、错误处理、返回值语义
- TOCTOU显式评估：“先查后操作”须评估并发
- 评论去重与合并：主评论区禁止复制摘要；suggestion区禁止粘贴评估表格/摘要片段，出现即判审查无效
- 执行流验证：确认调用时上下文满足前置条件
- 审查提示词=审查状态机：条件分支无降级出口即缺失Error State
- 静默降级须声明：核心链路非核心依赖的静默吞错须注释表达“预期即失败”
- suggestion疲劳归档：第2轮未修复降级，第3轮强制归档
- 微小增量精简：quick下纯修复≤200字；精简不允许遗漏实质性风险提示
- 模式复制焦点转移：已验证一致转向“适配性”；须显式列出差异点及理由；嵌套新上下文追问内容是否适合该模式
- 修复验证须含调用链：标“已修复”须验证上下游一致
- quick历史问题协议：增量与追踪项无交集可省略追踪表
- 修复即清除标签：修复后从主评论移除，仅保留已修复表
- 决策状态同步：阻塞项全修复且无新增时decision必须升级
- 归档≠阻塞：技术债务归档不继续影响当前决策
- 状态机思维：标签状态变更后标识必须同步
- 空评论结构约束：quick下无新增问题主评论强制为空
- 规则执行防形式化：根因是生成倾向填充空白，解决方向是结构约束
- 复合问题拆分约束：含多个独立子问题须编号，部分修复标“部分修复”
- 根因修复验证：引用高危区标签须回溯核心要求
- 历史问题消失检测：每轮显式清点上轮所有open项去向
- 问题描述粒度决定闭环质量：复合问题写一条→只修明显部分→假闭环
- 验证性内容≠suggestion：修复确认误标导致归档混乱
- “已有模式”≠可接受：应标warning归档；禁止混入suggestion区；标[minor]即违反判定规则
- 受限信息禁止确定性声明：quick下结论须用“在可见范围内”限定或省略
- “三件套完备”声明需证据：视为需diff证据的声明
- 空评论+高分组合信号：连续出现评分需校准
- “假实现”识别模式：功能类已使用但效果缺失须回溯配置层
- 跨层截断风险：模板截断+客户端解析为固有语法破坏风险，标准检查项
- 渲染内容兼容性评估：添加Markdown/HTML解析须检查历史字段含#*_等字符，未转义未禁用解析须标warning
- 低置信度标签过滤：置信度<0.5且无语义交集直接丢弃
- 知识性问题快速闭环：纯事实查询直接引用代码逻辑与行号
- 重复检测附带对比说明：判断可能重复须加相似度说明
- 转义逻辑复用检查：新增/修改转义函数须横向扫描同模块重复定义或调用缺失，重复归为技术债务
- 微小增量同类调用扫描：quick下涉及用户输入交互API（如str.format）须做全文关键字符扫描，结果一句话声明
- 降级渲染为保守安全策略：移除解析降为纯文本是应对跨层截断的标准处置

## 代码高危区
- 路径安全：resolve()跟随symlink；三层防护范式
- 适配器接口契约：首次审查须列所有公共方法逐一确认
- 回退链异常语义：禁止NotImplementedError表示“不支持”
- 参数静默忽略：违反为major
- 动态类型反模式：type()动态构造绕过静态检查
- 接口实现删除：列消费者→确认完备性→无法确认按critical
- 结构化数据解析：每字段类型假设须显式校验
- 降级链隔离：每阶段独立异常边界
- str.find()返回-1切片陷阱：须显式验证
- 无契约鸭子类型：隐式依赖使删除/替换无法静态发现
- 去重key设计：默认值碰撞、维度不足、丢弃无日志均为反模式
- 布尔参控制行为：改变返回值类型是职责模糊信号
- 错误处理策略分裂：同服务内抛异常vs静默降级共存须升级
- 双路径对称性：多路径解析的后处理逻辑结构一致性是核心不变量
- 花括号注入：用户输入传入str.format()须先转义花括号

## 严重程度判定
- 三问法强制绑定：[major]前须内联三问答案；任一为“无”自动降级minor
- 自评矛盾自动降级：正文出现“非安全/影响极小/风险可控”标签降级
- 纯可读性封顶规则：不涉功能/安全/数据完整性封顶suggestion
- 安全类禁止降级：已证明被防护允许降级
- 评论格式硬校验：[major]/[critical]须含文件:行号+问题+影响
- 分区标签解耦：“建议（可选）”禁止major/critical
- quick噪声过滤：纯改善性建议quick下不提出
