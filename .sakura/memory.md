# 项目记忆

## 审查模式与教训
- 规则与实际冲突须回溯适用性；分析否定须降级
- 路径安全证明须构造具体攻击路径；resolve()位置决定安全语义
- “部分修复”比“未修复”更危险；修复有效性须推演执行流，杜绝仅文档化假修复
- except ImportError是降级信号；回退链异常禁止NotImplementedError
- 增量审查陷阱：隧道视野、零评论高分、打勾陷阱；幽灵变更（新功能+修复混合易漏审配置默认值变更）须强制PR描述文件与审查覆盖一致性校验，遗漏即标[missing]并降级
- 评分决策解耦：未闭环critical时decision降级；评分须反映审查输出质量
- 防御代码隐形流失；遗留“存而不查”是假记忆
- 策略按风险密度选；PR描述覆盖校验：每个改动点须映射评论，并核对实际diff文件集
- 公开接口强制契约、错误处理、返回值语义三维度
- TOCTOU显式评估：“先查后操作”须评估并发；安全TOCTOU为系统性弱点，应推荐绑定操作消除窗
- 评论去重与合并：主评论禁复制摘要；suggestion禁粘贴表格/摘要片段
- 执行流验证：确认调用上下文满足前置条件
- 静默降级须声明注释；suggestion疲劳归档：第2轮未修复降级，第3轮强制归档
- 微小增量精简：quick下纯修复≤200字，不得遗漏实质性风险
- 模式复制焦点转移：已验证一致转向“适配性”，显式列出差异点
- 修复即清除标签；决策状态同步；归档≠阻塞；状态机思维
- 历史问题消失检测：每轮清点上轮所有open项去向
- 验证性内容≠suggestion；已有模式≠可接受，须标warning归档
- 受限信息禁止确定性声明；quick下结论限定“可见范围内”
- 空评论+高分组合信号；假实现识别须回溯配置层
- 跨层截断为固有风险，标准检查项；渲染兼容性须检查历史字段特殊字符
- 微小增量同类调用扫描：用户输入交互API须全文扫描关键字符
- 降级渲染为保守安全策略
- 配置默认值变更强制风险评估（攻击面、成本、向下兼容），标[major]以上
- 生命周期方法（reset_/init_/close_）无调用点即为major
- 配置假值陷阱：统一用is not None，避免0/空合法值失效
- AI自身prompt变更须强制评估提示注入、语义漂移，禁止仅作可读性处理
- 成本评估须区分默认免费与运行时多provider成本，禁依赖单一假设
- 已文档化风险不能标“已修复”，须归档为技术债务防假闭环

## 代码高危区
- 路径安全：resolve()跟随symlink；三层防护范式
- 适配器接口契约；回退链异常语义；参数静默忽略
- 动态类型反模式；接口实现删除；结构化数据解析
- 降级链隔离；str.find()切片陷阱；无契约鸭子类型
- 去重key反模式；布尔参控制行为；错误处理策略分裂
- 双路径对称性；花括号注入
- SSRF防护：DNS重绑定、IP限制健壮性；TOCTOU窗口
- 配置双源同步一致性（内存与持久化）
- 工具分组语义与权限开关的意外行为

## 严重程度判定
- 三问法强制绑定：[major]前内联答案；任一“无”自动降级
- 自评矛盾自动降级；纯可读性封顶suggestion
- 安全类禁止降级；评论格式硬校验：[major]/[critical]含文件:行号+问题+影响
- 分区标签解耦；quick噪声过滤（纯改善性建议不提）
