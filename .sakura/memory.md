# 项目记忆

## 核心审查教训与模式

- **双重处理陷阱**：同一格式化函数在调用链重复执行，扫描数据全路径同名调用，标critical
- **服务层职责模糊**：comment_service为评论渲染唯一入口，禁止上游预渲染；违反标critical
- **历史问题闭环验证**：声称修复须列出所有调用位置、冲突消除证据，缺失触发missing-statement
- **增量审查陷阱**：隧道视野致配置假开关、数据流断裂；必须扫描受改动字段影响的下游模块；发现新字段须追踪全生命周期，缺环节标major；删除导入前必须全仓库引用搜索（标minor）
- **降级标志全生命周期追踪**：引入布尔降级标志时，必须检查所有赋值点、重置点、使用点，确保无路径绕过；缺失标major
- **异常处理器顺序敏感性**：多个@app.exception_handler注册顺序决定优先级，标major
- **跨层导入强制注释**：API模块从WebUI层导入依赖时，必须注释理由，否则标minor
- **全局异常处理器禁止引用业务依赖**：不得解析token、查数据库、调用get_settings()，违反标major
- **重复代码提取权衡性能**：高频场景6次以上独立调用需批量聚合，标suggestion
- **静默异常禁止**：所有`except Exception`必须记录日志（顶级循环除外），违反标major
- **可变单例并发安全**：@lru_cache返回的对象若被setattr修改，须注释并发安全策略，标minor
- **语义版本验证**：版本号升级时须检查变更幅度与PR描述是否对齐，缺失标suggestion
- **配置热更新验证**：新增动态配置字段必须说明是否支持运行时热更新，缺失标major
- **注释与UI分组一致性**：字段声明的注释分组必须与UI分组实际归属一致，标minor
- **注释引用符号存在性检查**：注释中的函数/方法名必须在当前代码库中存在且行为一致；引用私有方法须加稳定性风险注释（标minor）
- **PR描述与变更内容一致性**：描述声称的功能（如配置重组、动画添加、Issue实现）必须能在变更文件列表中找到对应改动，缺失标critical
- **视觉特性真实性验证**：PR描述中的动画、飘落效果、UI组件必须验证DOM元素存在、CSS类已定义、无拼写错误，缺失标critical
- **副本同步强制标注源位置**：复制代码时注释必须包含源文件路径+行号范围，否则标minor
- **临时选择器必须标注移除版本/日期**：脆弱选择器（如基于Tailwind类名的CSS）除TODO外，必须注明计划移除目标，否则标minor
- **连续3轮未根治问题自动升级严重度**：同一问题在三轮PR中仅被注释缓解未修复，应从suggestion升为major
- **国际化覆盖完整性检查**：PR声明i18n时，必须扫描所有模板、路由toast、JS字符串、API错误消息，确保无硬编码用户可见文本，标major
- **重复工具函数/常量出现≥2次必须提取**：`_t()`类辅助方法或`language_names`类字典重复定义标minor
- **document.write禁止用于动态内容注入**：改为x-text、innerText或textContent，违反标major
- **toast消息必须使用i18n函数**：所有toast_redirect调用处必须动态选择语言字符串，标major

- 批量冲突检测中的动态集合维护
- PyGithub的get_contents()多态返回处理

- 临时CSS兼容层（基于Tailwind类名的脆弱选择器）

## 近期审查模式总结
- **配置全链路追踪**：新增配置字段须验证定义→分组→标签→SQL初始化（含迁移脚本）→所有消费点→热更新→测试覆盖，缺一环节标major
- **增量审查必须扫描PR描述中的所有提及文件**：即使提交列表不含某文件，若PR描述提到（如SQL、UI、动画资源），必须确认是否已存在或被遗漏，否则标major
- **重复逻辑阈值判断**：两处重复可容忍但须加注释标记未来重构点；出现第三处必须提取共享函数（Jinja2宏或`{% include %}`），标minor
- **开关可观测性强制**：新增降级/功能开关必须在关键路径记录info日志（含开关状态），高频路径用debug级别
- **死代码保留须注释**：保留未调用的条件分支时，必须注释预期调用者或未来用途，否则标minor；注释中禁止硬编码私有方法名
- **SQL字段默认值安全**：新增布尔开关默认True保持旧行为，INSERT须用IGNORE或ON DUPLICATE KEY UPDATE确保幂等；默认值变更需评估已有数据迁移，标major
- **版本号单一真实源**：版本号升级PR必须验证`__version__`集中定义、其他位置动态读取，否则标major；必须同步更新CHANGELOG（标minor）；孤儿变量（定义了未被导入）标major
- **无障碍一致性传播**：若一个页面有`prefers-reduced-motion`，同类页面必须同步检查，遗漏标minor
- **动画性能评估**：新增大量绝对定位+无限循环动画时，必须评估低端设备GPU图层暴涨风险，标major
- **深色模式对比度验证**：毛玻璃效果（如`bg-white/70`）在深色模式下必须验证文字对比度≥4.5:1，标major
- **响应式兼容性**：新增padding/圆角/阴影时，必须验证窄屏下无布局溢出或横向滚动，标minor
- **脆弱选择器标注**：基于Tailwind工具类名的CSS选择器必须标注“脆弱，仅临时过渡”注释，否则标minor
- **PR评分趋势分析**：若连续多轮评分相同（如8→8→8），审查应说明“为何未进步”或“债务被接受”，标suggestion
- **副本同步的完整性验证**：审查时须diff对比源与副本的实际代码，防止注释说谎，标minor

## 需特别关注的领域
- **跨语言版本同步**：Python main.py/auth.py + SQL init.sql + 迁移脚本必须构建时注入，防漂移；SQL默认版本与`__version__`须在同一事务或迁移脚本中同步
- **增量审查的风险升温检测**：历史问题在新功能上线后可能升级严重度；注释债务连续多轮未修复应主动升级
- **测试真实性验证**：mock必须匹配实际异常类型，断言异常路径被真正触发
- **并发竞态**：update_settings_field的setattr操作在异步环境需加锁评估
- **配置字段全生命周期清单**：定义→分组→标签→SQL初始化（含迁移）→所有消费点→热更新→单元测试
- **版本号升级检查清单**：强制验证单一真实源、CHANGELOG、Issue实现状态、fallback同步、孤儿变量消除
- **PR描述逐条验证**：每条声称功能必须在变更文件中可追溯，缺失时阻断合并
- **动画性能与无障碍**：飘落/无限循环动画必须包含`prefers-reduced-motion`尊重、性能回退方案
- **i18n前端集成完整性**：JS端window._t必须在所有Alpine/HTMX组件中可用，API返回JSON错误消息需翻译
- **样式副本漂移检测**：login/register等独立页面与base.html的共享样式需建立可执行的同步检查机制
- **临时兼容层生命周期追踪**：脆弱选择器必须标注预期移除版本，逾期未移除应触发重构PR
