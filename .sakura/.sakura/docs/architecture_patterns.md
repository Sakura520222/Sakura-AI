# 架构模式与设计决策

## 分层架构
- **API 层、服务层、数据访问层分离**：路由层禁止直接操作数据库
- **服务层自治事务模式**：服务方法内部自行 commit
- **权限策略单一真实源**：所有角色判断调用策略函数

## 配置管理
- **配置三层穿透**：Settings → yaml_config → 硬编码默认值
- **动态配置系统**：`get_dynamic_config` 统一接口，处理 None/非法值降级并记录 warn
- **配置默认值唯一声明**：禁止双源默认值

## 异步处理
- **幂等共享信号模式**：取消任务时多排队任务共享 asyncio.Event
- **批量操作 savepoint 模式**：循环中使用 `begin_nested()` 替代全局 rollback
- **异步任务调用方式统一**：同一模块中禁止混合 `create_task` 与 `await`

## 错误处理
- **全局异常处理器不得引用业务依赖**
- **服务层异常处理规范**：静默异常必须记录 debug 日志，并向调用方返回失败详情
- **失败状态传播需显式可恢复类型**：强制要求失败类型枚举

## 前端与模板
- **i18n 门面模式**：`render_template` 统一注入 `_()` 和 `lang`
- **模板 JS 插件安全规范**：强制使用 `|tojson` 进行 JS 上下文转义，禁止仅用 `|e`
- **外部可见链接必须通过统一链接服务生成**

## 数据库与事务
- **批量操作返回值规范**：必须返回结构化结果（如 `{"success": int, "skipped": List[str]}`）
- **事务外的外部写入必须支持补偿或异步**
- **新增 DB 模型的 datetime 字段必须使用 `datetime.now(timezone.utc)`**

## 审查与质量
- **微小变更审查价值**：行数少 ≠ 风险低
- **增量隧道视野**：对新增字段完整生命周期缺乏追踪
- **"删除优于修复"模式**：冗余功能删除比修补安全

## 工具与插件
- **工具插件化架构**：统一工具注册与调用
- **集中式结果解析器**：AI 输出清洗收敛于 `result_parser.py`
