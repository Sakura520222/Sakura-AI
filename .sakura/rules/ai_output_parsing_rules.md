# AI 输出解析鲁棒性规则

## 核心规则

### 协议模板字段缺失处理
- **强制降级**：协议模板必填字段（如 `SUGGESTED_TITLE`、`DUPLICATE_OF`）缺失时必须触发降级路径，禁止静默失败
- **字段级别隔离**：单标签缺失不应导致整条分析链路崩溃，各模块须独立解析、独立降级

### 防御性编程规范
- **大小写容错**：AI 输出解析须处理字段名的大小写变体（如 `suggested_title` / `SUGGESTED_TITLE`）
- **拼写纠错**：处理常见拼写错误或部分字段缺失场景
- **空值安全**：所有字段访问须使用 `dict.get()` 或显式 None 检查

### 错误信息隔离
- **禁止内部异常泄漏**：解析异常不得直接暴露给用户，必须转换为用户友好的错误提示
- **错误分级处理**：格式错误 → 降级为部分结果；语义错误 → 标记解析失败请求重试

### 工具链故障优先级
- **核心自动化失效**：导致核心功能（如 Issue 分析）完全不可用的工具链故障优先级不得低于 `medium`
- **降级输出要求**：主解析路径失败时，降级路径必须输出：错误类型、原始输入摘要、建议操作

## 审查要点

- [ ] AI 输出接口是否包含字段缺失处理
- [ ] 是否对大小写、空值、拼写错误做容错
- [ ] 解析失败时的错误信息是否脱敏
- [ ] 单字段缺失是否影响其他字段解析
- [ ] 工具链故障优先级评估是否准确
