# Python 语法一致性规则

## 核心规则

### Python 2/3 兼容性
- **禁止 Python 2 语法**：新引入代码不得包含已废弃的 Python 2 语法
  - `print` 语句（必须使用 `print()` 函数）
  - `except Exception, e:` 逗号语法（必须使用 `as`）
  - 旧式字符串格式化（`%` 操作符）
- **违反级别**：Critical（阻断整个模块导入链）

### 基础语法错误
- **放射性影响**：基础模块的语法错误会阻断整个导入链
- **测试不等于正确**：语法错误可能导致测试框架无法加载被测模块
- **审查优先级**：基础语法正确性优先于业务逻辑审查

## 审查要点

### 语法检查
- [ ] 是否有 `except Exception, e:` 逗号语法
- [ ] 是否有 `print` 语句
- [ ] 是否有旧式字符串格式化
- [ ] 是否有 `xrange`、`raw_input` 等 Python 2 函数

### 导入链验证
- [ ] 基础模块能否被正常导入
- [ ] 1-2 个直接依赖该模块的上层模块能否正常导入
- [ ] 是否存在循环导入

### 测试有效性
- [ ] 测试环境 Python 版本与生产环境是否一致
- [ ] 测试是否真的加载了被测模块
- [ ] 语法错误是否导致测试框架本身失败

## 常见陷阱

- 复制粘贴代码时带入旧语法
- 混用不同 Python 版本的代码片段
- 依赖项目自动修复工具但未人工复核
