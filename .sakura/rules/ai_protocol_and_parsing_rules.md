# AI 结构化输出解析与协议适配防线规则

## 一、AI 响应解析与容错收敛规则

### 1.1 严禁裸调 `json.loads`
1. **统一提取与清理工具**：在解析 LLM 输出的结构化内容时，严禁直接调用 `json.loads`。必须统一调用内置 Markdown 代码块剥离与清洗工具（如带 recovery 引导的解析函数），防御模型返回包含前缀解释、` ```json ` 围栏或尾部思考内容。
2. **多阶段管线 Schema 降级防御**：在多角色 AI 流水线（如“总结辅助模型 → 候选 → 裁决主模型”）中，必须在阶段交接处设立防御性校验，防止上游响应结构不符合预期直接引发下游异常。
3. **模型故障显式提示**：模型调用全盘失败或遭遇不可恢复的畸形响应时，必须显式抛出特定语义错误（如“治理服务暂时不可用”），严禁静默生成假装成功的空报告。

---

## 二、第三方兼容协议适配与数值边界防线

### 2.1 协议适配层边界安全
1. **严格区分 `0` 与 `None`**：在 OpenAI Compatible 适配层处理第三方网关（如 OneAPI、NewAPI、LiteLLM）返回时，`reasoning_tokens`、`output_tokens` 等用量字段在遇到缺失（`None`）与有效数值 `0` 时必须区分判定，严禁使用盲目的假值（falsy）判断导致 `output_tokens=0` 异常覆盖。
2. **严防 `bool` 伪装 `int`**：在校验整数配置或参数时，由于 Python 中 `isinstance(True, int)` 为真，必须使用 `type(x) is not int` 显式拦截布尔值。
3. **行号与分页物理钳制**：任何由模型生成或客户端传入的行号、切片、分页偏移参数，在进入核心引擎前必须实施物理上下界强行钳制（Clamp）。
