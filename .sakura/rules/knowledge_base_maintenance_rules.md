# 知识库维护规则

## 核心原则

**知识库变更须等同代码变更审查**

删除规则、覆盖式更新等操作具有不可逆影响，必须经过严格审查。

## 强制规则

### 覆盖式更新禁止
- **禁止知识资产回退**：不得使用覆盖式更新导致核心规则丢失、反思次数倒退
- **增量更新优先**：知识添加应采用追加方式，保留历史版本

### 删除规则规范
- **逐项说明理由**：删除任何规则必须逐项说明删除原因
- **影响评估**：须评估删除规则对未来审查的影响
- **替代方案**：如果规则过时，须提供替代方案或迁移路径

### 知识负债监控
- **定期审查**：每月检查是否有知识负债累积（经验丢失、规则退化）
- **版本标记**：重要规则变更须记录版本号和变更原因
- **回滚计划**：重大知识变更须制定回滚计划

### 引用完整性
- **删除前检查引用**：删除规则前必须检查是否有其他文档或代码引用
- **索引更新**：规则变更后必须同步更新索引和目录

## 违规后果

- 知识资产回退 → **Critical**
- 无理由删除规则 → **Major**
- 覆盖式更新未备份 → **Major**
- 引用完整性破坏 → **Major**

## 审查清单

- [ ] 变更类型（新增/修改/删除）
- [ ] 是否采用增量更新
- [ ] 删除规则的替代方案
- [ ] 对其他文档的影响
- [ ] 是否需要版本回滚计划
- [ ] 是否更新了索引
